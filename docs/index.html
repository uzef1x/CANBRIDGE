CANBRIDGE Web Installer

Nissan LEAF / e-NV200 battery-upgrade CAN bridge for the LilyGo T-2CANFD (ESP32-S3). This page flashes the firmware over USB from a Chrome or Edge browser.

Step 1: Attach the board

Plug the LilyGo T-2CANFD into your computer with a USB-C cable. Power it from USB only while flashing (no 12 V on VIN).

Loading the latest firmware…

Step 2: Install

Click the button, pick your board's serial port, and choose Install. Select "Erase device" on a first-time install.

Step 3: Select the profile

One firmware serves both cars; the choice is stored on the device and read at boot. Close the installer dialog first (it holds the serial port), then click:

Device output appears here.

After the device confirms the choice was stored, press its RST button (or unplug/replug) — the selection takes effect on the next boot. The default — before any selection is made — is Monitor: a safe pass-through that modifies nothing.

Troubleshooting

If the device is not detected when connecting, hold the BOOT button while clicking Connect, and release it once erasing/installing starts.
